# 可视化跨端后台构建器（路线图，暂不开发）

> 目标：在本后台上叠加“页面可视化编排 + 多端模板插件 + 一键打包”，
> 后台配页面，前端按模板生成 PC / H5 / 小程序 / APP 包。复杂度高，先记录设计，后续立项。

## 1. 形态

- 后台新增「页面设计器」插件：拖拽布局组件（表单/表格/图表/导航），产出**页面 Schema JSON**
  （版本化存表 `page_schemas`，含布局树 + 数据源绑定 + 事件）。
- 模板插件（与业务插件同机制）：`pc-web`（Vue3）、`h5`、`miniapp`（uni-app x）、`app`，
  每个模板插件实现 `render(schema): 产物`，产物 = 可构建的前端工程片段或完整包。
- 打包服务：按 平台×模板 生成产物包（zip / 源码工程），经构建流水线（vite / uni-app x CLI）
  出最终包，前端直接发行。

## 2. 后端契约（复用现有）

- Schema 存取走统一信封接口（`$this->ok/fail/page`，见 AGENTS.md §3）；
- 模板插件挂 `PluginInterface`，路由 `/api/builder/...`，菜单经 `menus()` 聚合；
- 打包任务走队列（`queue:work` 常驻消费，大包异步化，进度经事件推送）。

## 3. 分阶段

1. Schema 表 + 设计器读写接口（无 UI，先 JSON）；
2. `pc-web` 模板插件（Vue3 片段生成，打通预览）；
3. `miniapp`/`h5` 模板（uni-app x 工程生成）；
4. 打包流水线 + 版本管理 + 回滚。

## 4. 风险

- 模板与前端框架版本耦合（锁定 vue-pure-admin / uni-app x 版本，升级需回归）；
- 生成代码的可维护性（产物只读，二次开发回设计器改）；
- 安全：Schema 即代码，渲染层严格白名单组件，禁止任意 JS 注入。
